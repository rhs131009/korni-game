# Корни — тренажёр задания 9

Откройте `index.html` в браузере. Установка и интернет не нужны. Рядом должны лежать `data.js` и `app.js`.

335 упражнений по темам предоставленного документа: проверяемые гласные, чередующиеся корни, непроверяемые гласные. Это учебная выборка, не полный словник и не имитация формата экзамена с рядами слов. В банке использованы слова из словника и дополнительные примеры на перечисленные в документе корни. Некорректная запись «зар//зар» из исходника исправлена на «зар//зор».

Возможности: выбор темы, пояснение после ответа, статистика, список ошибок, повтор ошибок. Верный ответ в режиме повторения удаляет слово из списка. Сброс счёта сохраняет список ошибок; для него есть отдельная кнопка. На клавиатуре можно вводить русскую гласную, Enter переключает слово (если фокус не на кнопке или списке).

## GitHub Pages

1. Создайте репозиторий в своём GitHub.
2. Загрузите `index.html`, `app.js` и `data.js` в корень репозитория.
3. Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
4. После публикации адрес появится на этой странице.

Игра создана с нуля, без копирования исходников accentsgame. Сторонних библиотек и аналитики нет. Статистика хранится локально в браузере.
