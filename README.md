# Корни — тренажёр задания 9

[Открыть тренажёр](https://rhs131009.github.io/korni-game/).

483 задания: 23 на проверяемые гласные, 79 на чередование, 354 на словарные гласные и 27 на другие орфограммы. Добавлены все 213 слов из дополнительного школьного списка; 137 из них отсутствовали в прежней базе. Уже имевшиеся слова не дублируются.

Тема определяется по пропущенной букве. Не каждое слово из школьного словарного списка содержит именно непроверяемую гласную: согласные, приставки, соединительные гласные и написания после шипящих и Ц выделены в «Другие орфограммы». Это учебная выборка, а не полный словник или имитация экзамена с рядами слов.

Слова показываются в случайном порядке. Уже встречавшиеся карточки с вероятностью 30% возвращаются между новыми, когда есть подходящие для повторения слова. Последние пять карточек не повторяются сразу; в небольших темах интервал сокращается. Если в ошибках осталось одно слово, оно повторяется до правильного ответа.

После ответа появляется объяснение. Ошибки сохраняются в отдельном списке. Верный ответ удаляет карточку из ошибок. Сброс счёта сохраняет ошибки; отдельная кнопка очищает их. Русские буквы вводятся с клавиатуры, Enter переключает слово после ответа. Повторное нажатие не добавляет попытку.

Прогресс хранится локально в браузере. Некорректные или устаревшие записи сохранения не мешают запуску. Если хранилище браузера недоступно, тренировка работает без сохранения.

Для работы без интернета скачайте index.html, app.js и data.js в одну папку, затем откройте index.html. Внешних библиотек и аналитики нет.

Проверены все карточки на соответствие ответа пропущенной букве, уникальность и доступность правильной кнопки. В браузере проверены все темы, кнопки, раскрытие правил, ввод с клавиатуры и сохранение после перезагрузки.
